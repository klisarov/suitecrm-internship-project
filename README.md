# SuiteCRM Internship Project

A custom SuiteCRM 7 internship project developed with PHP 8.2.

## Project Overview

This repository contains the custom development work completed as part of my SuiteCRM internship.

The project focuses on understanding and implementing SuiteCRM 7 development concepts using PHP and the SuiteCRM framework.

## Technologies

- SuiteCRM 7.15.2
- PHP 8.2
- MySQL
- JavaScript
- jQuery
- Git

## Learning Objectives

The project covers:

- Custom module creation
- Vardefs and custom fields
- Metadata
- Relationships
- Subpanels
- Search functionality
- Logic Hooks
- JavaScript integration
- Validation
- Testing
- Technical documentation
